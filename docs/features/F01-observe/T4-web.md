# T4: React + TS, список и страница запуска

**Цель:** увидеть запуски и таймлайн в браузере.

## Кто что пишет
- Агент: весь `web/` (vite react-ts, генерация типов, прокси, компоненты, хуки, `zod`, роутинг).
- Владелец: принимает результат по критериям приёмки, глубоко код не читает. Проверяет в браузере и по `tsc`/линтеру.

## Контекст
- T3: `openapi.yaml` и сгенерированные типы.

## Что сделать
1. `strict: true` в tsconfig. Без `any`.
2. API-слой: функции `fetchRuns`, `fetchRun`; ответы проходят через `zod`-схемы, типы выводятся из схем и сверяются с типами из OpenAPI.
3. Страница `/`: список запусков (статус, cwd, task_text, время, длительность), кнопка «ещё» для пагинации.
4. Страница `/runs/:id`: таймлайн событий, раскрываемые детали (payload), подсветка ошибок (`PostToolUseFailure`).
5. Состояния загрузки и ошибки. Токен из `import.meta.env`.
6. Без UI-библиотек и дизайна, только читаемая вёрстка.

## Критерии приёмки
- Живая сессия Claude Code появляется в списке после обновления страницы.
- Некорректный ответ сервера даёт понятную ошибку, а не падение рендера.
- `tsc --noEmit` и линтер чистые.
- Агент прогнал страницы в реальном браузере против живого бэкенда и приложил скриншоты списка и таймлайна.

## Вне тикета
Живое обновление (SSE), фильтры, тёмная тема, тесты компонентов.
